# Ashel Gym — интерактивное превью

Самостоятельная веб-версия мобильного приложения для портфолио. React, TypeScript, Vite и Zustand. Сервер, Expo, SQLite, переменные окружения и авторизация не требуются.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Откройте адрес из терминала. На компьютере приложение отображается в корпусе телефона; на экранах уже 480 px занимает всю доступную область. Корпус адаптируется к высоте окна без изменения масштаба браузера.

```sh
npm test            # Сценарии локального хранилища и обработки данных
npm run typecheck   # Проверка TypeScript
npm run build       # TypeScript и статическая production-сборка
npm run preview     # Локальный просмотр сборки
```

## Что можно попробовать

- **Profile:** шесть групп мышц, все 46 оригинальных упражнений, рабочий и максимальный вес, редактирование, история и SVG-графики.
- **Training:** начать тренировку, выбрать группы мышц и упражнения, добавить и удалить подходы, изменить вес и повторения, завершить тренировку.
- **Calendar:** переключить месяц, открыть день, посмотреть упражнения и подходы, сводку тренировок, подходов и объёма нагрузки за месяц.
- **Demo:** сбросить изменения и заново заполнить пример истории за последние два месяца.

Изменения сохраняются в `localStorage` под ключом `ashel-gym-demo-v1`. Незавершённая тренировка восстанавливается после перезагрузки. У каждого посетителя свои данные. Если хранилище заблокировано или переполнено, приложение показывает уведомление и продолжает работать в памяти.

Вес допускает точку или запятую, значения от 0 до 9999 кг. Повторения — целые числа от 1 до 999. Полностью пустую тренировку завершить нельзя. Изменение веса в Profile сохраняет запись в истории; веса подходов и персональные показатели редактируются независимо, как в исходном приложении.

Интерфейс сохраняет английские подписи и тёмную палитру оригинала. Все данные демонстрационные. Нативные списки, изображения, ввод, навигация, модальные окна и графики заменены веб-технологиями. Вибрация и другие функции устройства не используются. Графики упрощены: статическая линия с доступными текстовыми значениями истории.

## Публикация

После `npm run build` разместите всё содержимое `dist` на любом статическом хостинге. Поддерживается размещение в подпапке: пути ресурсов относительные, навигация использует hash (`#/profile`, `#/training`, `#/calendar`). Серверное перенаправление маршрутов не требуется.

## Исходники и ресурсы

`src/catalog.json` — перенесённый каталог. `src/model.ts` — типы, демо-данные и сводки. `src/store.ts` — состояние и сохранение. `src/App.tsx` и `src/styles.css` — веб-интерфейс и корпус телефона. Ресурсы находятся в `public/assets` и не требуют доступа к исходному мобильному проекту.

`scripts/import-assets.mjs` — вспомогательный скрипт первоначального переноса из локального React Native проекта. Для запуска и сборки сайта он не нужен. Исходное приложение и nutsfarm не изменяются.
